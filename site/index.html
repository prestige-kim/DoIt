    Windows 다운로드 준비 중

    x64용 다운로드 Arm64용 다운로드

    1. 시스템 종류 확인

      설정 → 시스템 → 정보에서 시스템 종류를 확인하고 x64 또는 Arm64용 설치 파일을 고릅니다.

    2. 설치 파일 열기

      다운로드한 DoIt 설치 파일을 열고 화면의 안내를 따릅니다. 현재 Windows 계정에 설치됩니다.

    3. 트레이에서 열기

      시작 메뉴에서 DoIt을 실행한 뒤 시계 옆 DoIt 아이콘을 누릅니다. 처음에는 작업 표시줄의 ^(숨겨진 아이콘) 안에 있을 수 있습니다. 항상 보이게 하려면 설정 → 개인 설정 → 작업 표시줄 → 기타 시스템 트레이 아이콘에서 DoIt을 켭니다.

    경고가 나타나면

    이렇게 열어 주세요

    1. 브라우저가 ‘일반적으로 다운로드되지 않는 파일’처럼 경고하면, 이 페이지에서 받은 DoIt 설치 파일이 맞는지 확인한 뒤 ‘유지’를 고릅니다. Edge 기준이며 브라우저마다 문구가 다릅니다.
    2. 설치 파일을 열 때 ‘Windows의 PC 보호’ 창이 나오면 ‘추가 정보’를 누릅니다.
    3. 게시자가 ‘알 수 없는 게시자’로 표시되는지 확인하고 ‘실행’을 누릅니다. DoIt 설치는 관리자 권한을 묻지 않는 것이 정상입니다.

    설치 파일이 맞는지 확인하기

    설치 파일이 있는 폴더에서 PowerShell을 열고 아래 명령을 실행합니다. Arm64용은 파일 이름의 x64를 arm64로 바꿉니다.

    Get-FileHash .\DoIt-Windows-1.0.0-1-x64-Setup.exe -Algorithm SHA256

    나온 Hash 값이 이 페이지의 설치 파일 SHA-256과 같으면 공식 파일입니다. 다르면 실행하지 말고 지운 뒤 다시 받으세요. SHA-256 값은 다운로드가 열리면 함께 표시됩니다.

    업데이트

    새 버전이 나오면 DoIt이 설정과 트레이 메뉴에서 알려 줍니다. ‘새 버전 받기’로 설치 파일을 받아 실행하면 앱만 바뀌고 할 일과 설정은 그대로 남습니다. 앱이 저절로 설치하지는 않습니다. DoIt이 실행 중이면 트레이 아이콘 메뉴에서 먼저 종료한 뒤 설치하세요.

    제거

    설정 → 앱 → 설치된 앱에서 DoIt을 제거합니다. 할 일 데이터는 %LOCALAPPDATA%\DoIt 폴더에 남으므로, 지우려면 이 폴더를 직접 삭제하세요.

      피드 주소 저장

      DoIt 설정 → LMS 연동에서
      주소를 붙여넣고 ‘저장’을 누르세요.

      이미지 크게 보기 ↗
    2. 2

      연동 켜기

      ‘LMS 연동 켜기’를 켜세요.
      가져올 기간도 정할 수 있습니다.

      이미지 크게 보기 ↗

    Mac용 DoIt 설정 예시입니다. Windows에서도 DoIt 설정의 LMS 연동에서 주소를 저장합니다. 웹에서는 주소를 입력받지 않습니다.

    LMS 없이도 사용할 수 있어요.

    연동하지 않아도 할 일·달력·마감 알림을 사용할 수 있습니다.
    피드를 추가하지 않으면 패널에 LMS 칸이 나타나지 않습니다.

    피드 주소는 DoIt 앱 설정 창에만 직접 붙여넣으세요. 비밀번호처럼 보관하고 스크린샷·터미널·대화에 노출하지 마세요. 노출했다면 LMS에서 재발급하세요.

    한동대 LMS 기준이며 다른 학교는 미검증입니다. 학교 공식 앱이 아닙니다. LMS 원본이 기준이며 DoIt은 보조 도구입니다. 중요한 마감은 LMS에서 확인하세요.

    개인정보＋

    개발자는 사용자 데이터를 수집하거나 전송받지 않습니다. 할 일·과제·체크 상태·기록은 사용하는 기기에 저장됩니다.

    LMS에는 피드 GET 요청만 보냅니다. 할 일과 체크 상태를 보내거나 강의자료·게시글·첨부파일에 접근하거나 화면을 크롤링하지 않습니다. LMS 데이터를 AI 서비스에 보내지 않습니다.

    Mac에서는 피드 주소를 본인 계정 전용 파일에 저장합니다(파일 권한 600·폴더 700, Time Machine 백업 제외). Windows에서는 현재 Windows 사용자 계정으로 피드 주소를 보호합니다.

    Mac용 업데이트 확인과 설치 파일 다운로드는 GitHub와 통신하며 IP 등 일반 HTTP 정보가 전달될 수 있습니다.

    Windows판은 ‘새 버전 자동 확인’이 켜져 있으면 하루 한 번 이 소개 페이지의 버전 정보 파일을 받습니다. 할 일 데이터는 보내지 않으며, 이때도 IP 등 일반 HTTP 정보가 전달될 수 있습니다. 설정의 일반 탭에서 끌 수 있습니다.

    이 웹사이트에는 입력 수집·분석 도구가 없습니다.

    알림과 업데이트＋

    Mac에서는 마감 당일 오전 9시에 노치 알림을 모아서 표시합니다. 앱 종료 중 macOS 알림에는 알림 권한이 필요합니다. Windows에서는 오늘 마감인 건수만 알림 센터에 표시합니다. 기록은 자동으로 삭제하지 않습니다.

    Mac용 업데이트는 자동으로 확인하고 설치는 사용자가 선택합니다.

    Windows용은 앱이 새 버전을 알려 주고, ‘새 버전 받기’로 설치 파일을 받아 실행하면 할 일과 설정을 유지한 채 앱만 바뀝니다. 설치는 사용자가 직접 합니다.

    지원 환경＋

    macOS 14 이상. Apple Silicon 실사용 확인. Intel은 universal 빌드 확인, 실사용 미확인입니다.

    Windows용은 Windows 11 x64·Arm64용 설치 파일을 따로 제공하며, 관리자 권한 없이 현재 Windows 계정에 설치됩니다. 모바일에서는 웹 체험을 이용할 수 있습니다.
