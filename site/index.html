DoIt 설정 화면입니다. 개인 피드 주소는 포함하지 않았습니다. 웹에서는 주소를 입력받지 않습니다.

LMS 없이도 사용할 수 있어요.

연동하지 않아도 할 일·달력·마감 알림을 사용할 수 있습니다.
피드를 추가하지 않으면 패널에 LMS 칸이 나타나지 않습니다.

피드 주소는 DoIt 앱 설정 창에만 직접 붙여넣으세요. 비밀번호처럼 보관하고 스크린샷·터미널·대화에 노출하지 마세요. 노출했다면 LMS에서 재발급하세요.

한동대 LMS 기준이며 다른 학교는 미검증입니다. 학교 공식 앱이 아닙니다. LMS 원본이 기준이며 DoIt은 보조 도구입니다. 중요한 마감은 LMS에서 확인하세요.

개인정보＋

개발자는 사용자 데이터를 수집하거나 전송받지 않습니다. 할 일·과제·체크 상태·기록은 맥 안에 저장됩니다.

LMS에는 피드 GET 요청만 보냅니다. 할 일과 체크 상태를 보내거나 강의자료·게시글·첨부파일에 접근하거나 화면을 크롤링하지 않습니다. LMS 데이터를 AI 서비스에 보내지 않습니다.

피드 주소는 본인 계정 전용 파일에 저장합니다(파일 권한 600·폴더 700, Time Machine 백업 제외). 같은 계정의 다른 프로그램까지 차단하는 저장소는 아닙니다.

업데이트 확인·다운로드는 GitHub와 통신하며 IP 등 일반 HTTP 정보가 전달될 수 있습니다. 이 웹사이트에는 입력 수집·분석 도구가 없습니다.

알림과 업데이트＋

노치 알림은 마감 당일 오전 9시에 모아서 표시합니다. 앱 종료 중 macOS 알림에는 알림 권한이 필요합니다. 기록은 자동으로 삭제하지 않습니다.

업데이트는 자동으로 확인하고 설치는 사용자가 선택합니다. 로컬 업데이트에서 인증 창 0번을 확인했으며 다른 맥이나 실제 배포 경로의 결과는 보장하지 않습니다.

지원 환경＋

macOS 14 이상. Apple Silicon 실사용 확인. Intel은 universal 빌드 확인, 실사용 미확인입니다. 모바일에서는 웹 체험만 가능하며 앱은 Mac 전용입니다.
