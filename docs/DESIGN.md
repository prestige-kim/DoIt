# DoIt 디자인 확정안

> 확정: 2026-11-07 · 공개 문서 내부 참조 정리: 2026-11-09
> 이 문서가 화면 디자인의 기준이다. 수치(px)는 디자인 시안 기준이며 macOS에서는 pt로 그대로 쓴다. 바꿀 이유가 생기면 구현하지 말고 문서 관리 담당자에게 제안한다.
> 적용: T-011 ✅(색·배치·설정 창), T-005 ✅(노치 알림), T-006(전체 편집기 창), T-010(앱 아이콘·메뉴바 아이콘)
> 개정: 2026-11-08 T-011 확인 중 사용자 결정 반영 (노치 띠 머리줄, 어두운 모드 검정, 색 역할 추가, 달력 최대 높이) / T-005 확인 중 결정(노치 알림 색·hover) / T-006 전체 편집기 창 추가

## 방향
- macOS 기본처럼 깔끔하게 (시스템 글꼴, 과하지 않게)
- **밝은 화면 + 어두운 화면 둘 다** — 맥 시스템 설정을 따라 자동 전환
- 밀도: 중간 (macOS 미리 알림 앱 정도, 행 높이 약 36~46)
- 강조색: **내 할 일 = 이화 그린**, **LMS 과제 = 남색·파랑**, 지난 마감 = 빨강

## 앱 아이콘: D안 "검은 목록" (T-010)
- 검은 둥근 사각형(#161618) 바탕에 세 줄
  1. 초록 원 + 흰 체크 (#3FBF7F) + 밝은 줄
  2. 파란 점 (#6E9BFF, LMS) + 밝은 줄
  3. 회색 빈 원 (#6A6A70) + 회색 줄 (짧게)
- 메뉴바 아이콘: 같은 모양의 **단색 템플릿 이미지** (체크 / 점 / 빈 원 + 줄 3개), `isTemplate = true`
- `Assets.xcassets/AppIcon` 16~1024

## 노치 패널
- **노치에서 펼쳐짐 (2026-11-08)**: 접힌 상태는 검은 노치. 펼치면 노치 모양이 양옆·아래로 커지며 **노치 옆 메뉴바 띠까지 패널**이 되고, 검정이 패널 바탕색으로 바뀐다. 위 양 끝은 메뉴바와 이어지는 곡선. 노치 자리는 항상 검정을 겹쳐 그림
- 폭 약 440, 아래 모서리 14, 옅은 테두리(밝은 모드만) + 그림자(펼친 상태만)
- **머리줄은 노치 옆 띠 안**: 왼쪽 `DoIt 11/8(일)`, 오른쪽 📆(달력 화면에서는 목록 아이콘) · 편집기(`square.and.pencil`, T-006) · ⚙
- 띠 아래: 입력창(+ 아이콘, "할 일 추가…", 날짜 칩 "오늘") → **LMS 칸** → 구분선 → **내 할 일**
- LMS 칸 머리: 접기 화살표 · "LMS 과제" · 개수 배지 · 오른쪽 "2주 · 21:20 동기화"
- LMS 행: 파란 빈 원 · 과제명 · 아래 과목명 칩 · 오른쪽 D-day(굵게) + 날짜(작게). 지난 과제는 원·글자 빨강 + 옅은 빨강 바탕, "어제 마감"
- 내 할 일 행: 빈 원(회색) / 완료는 초록 원 + 체크 + 취소선·흐린 글자. 오늘 마감은 날짜 글자 초록
- 잘린 제목: 마우스를 올리면 아래에 어두운 말풍선으로 전체 제목

## 노치 알림 (T-005, 2026-11-08)
- 다이나믹 아일랜드처럼 **노치가 양옆으로 넓어진 한 줄 캡슐**. 바탕: **밝은 모드 흰색(패널과 같은 색), 어두운 모드 검정** (2026-11-08 사용자 결정)
- 높이: 노치 높이 그대로 또는 살짝 아래로(한 줄이 들어갈 만큼), 폭은 내용에 맞추되 패널 폭(440) 이하
- 왼쪽: 초록 점(내 할 일만) / 파란 점(LMS 포함) · `오늘 마감 n개` (굵게) · `HW3 [컴퓨터구조] 외 2개` (보조 글자)
- 오른쪽 끝: 작은 `×` 닫기 버튼 (원형, 보조 글자색, 마우스를 올리면 밝아짐)
- 펼침과 같은 spring으로 넓어지고, 5초 뒤 또는 `×` 시 노치로 줄어듦 (5초 유지 — 2026-11-09 사용자 확인)
- 마우스를 올리면 5초 닫힘을 미루기만 하고(펼치지 않음), **클릭하면** 평소 패널로 펼쳐짐

## 달력 보기
- 패널 폭 약 520, 최대 높이 화면의 70%·상한 640. 달 머리: "2026년 11월" · ◀ 오늘 ▶ (목록으로 버튼은 노치 옆 띠)
- 일~토 7칸, 칸 높이 약 54. 오늘 = 초록 원 숫자, 선택한 날 = 초록 테두리 + 옅은 초록 바탕, 지난 날짜 숫자는 회색
- 날짜 아래 점: 초록(내 할 일) / 파랑(LMS) / 빨강(지난 미완료 LMS), 완료는 흐리게(35%)
- 범례 + "지난 날짜는 보기만 가능"
- 아래: 선택한 날 목록(LMS는 과목 칩, 내 할 일은 "내 할 일" 칩) + 그 날짜가 미리 들어간 입력창
- 접혔다 펼쳐도 보던 달·선택 날짜 유지 (메뉴로 끄고 켜기·재실행 시 목록·오늘)

## 전체 편집기 창 (T-006, 2026-11-08)
- 약 760×560, 크기 조절 가능(최소 600×420). 바탕·글자·강조색은 패널과 같은 역할 색(어두운 모드 바탕 #000000), 시스템 글꼴
- 위쪽 도구줄: 검색창(돋보기, "제목 검색") · 정렬 세그먼트(**마감일순** / 추가순)
- 본문 두 칸(위→아래): **LMS 과제**(접기 가능, 패널 LMS 칸과 같은 행 모양: 파란 원·과제명·과목 칩·D-day, 체크만 가능, 수정 아이콘 없음) → **내 할 일**
- 내 할 일 행(높이 약 40): 왼쪽 **선택 체크박스**(작은 사각형) · 완료 원 · 제목 · 오른쪽 마감일 · D-day
  - 제목을 더블클릭(또는 행의 연필 아이콘)하면 그 자리에서 입력칸 → Enter 저장, Esc 취소, 밖을 누르면 저장
  - 마감일을 누르면 날짜 선택(달력). 고르면 바로 저장
- 하나 이상 선택하면 아래쪽에 **일괄 막대**: `n개 선택` · 완료 · 미완료 · 삭제(빨강) · 선택 해제. 삭제는 막대 안에서 `n개 삭제?`(빨강)로 한 번 더 확인
- 검색 결과가 없으면 "찾는 할 일이 없어요"
- 브라우저 경고창(alert·confirm) 쓰지 않음 — 확인은 화면 안에서

## 설정 창
- 약 720×540, 바탕 한 색(어두운 모드 #000000), 왼쪽 사이드바(일반 / LMS 연동 / 알림 / 기록 보관 / 저장 공간), 선택 항목은 옅은 초록 바탕
- 오른쪽: macOS 설정처럼 둥근 묶음 상자 안에 행(제목 + 작은 설명, 오른쪽에 스위치·버튼)
- 일반: 로그인 시 자동 실행(T-010, 기본 끔), `자동으로 업데이트 확인`(T-012b, 기본 켬·설명 ‘하루 간격으로 새 버전을 확인해요. 설치는 직접 선택해요.’), `업데이트 확인…` 버튼, 버전. 진행 중 버튼 비활성, 주소 준비 전에는 ‘업데이트 준비 중’ 안내. 노치 패널에 업데이트 조작을 추가하지 않는다.
- LMS 연동: 켜기 스위치 / 피드 주소 "🔒 이 맥에만 저장됨"(T-013) + 변경… / 가져올 기간 − 2주 + / 마지막 동기화 + 지금 새로고침 / 안내 문구 / 연결 해제…(빨강)
- 알림 (T-005): 내 할 일 마감 알림, LMS 과제 알림(마감 당일 오전 9시), 노치 알림 일시 중지, 다음 알림 미리보기, 테스트 알림 보내기, (권한 거부 시) 앱 종료 중 알림 안내
- 기록 보관: 보관 기간 세그먼트(6개월 / **1년** / 2년 / 정리 안 함), 정리 대상 n개 + 지금 정리…, 모든 기록 초기화…(빨강)
- 저장 공간: 파일별 개수·크기 표, 합계, DoIt 메모리, 새로 계산, 위치 안내

## 배포 랜딩 최종 디자인 (2026-11-10 현행화)
이 절은 T-012d 사용자 A~E 확인을 반영하며 macOS 앱 디자인을 변경하지 않는다. 초기 sticky 제품 쇼케이스 방향보다 이후 사용자 수정 요청이 우선한다.

- 제목 ‘할 일과 과제, DoIt에서’, 시스템 서체·절제된 굵기·한 줄 기능 설명. 단계 번호/장문 홍보/중복 예시 문구 제거. 설치와 접힌 사용 안내로 필수 정보를 유지한다.
- 제품 무대는 초기 HTML/CSS 화면 테두리·얇은 하단 프레임, 키보드/스피커/트랙패드 없음. 사용자 지정 뉴욕 배경·메뉴바 crop·현재 날짜/시각. 공개 사용 조건 확인은 별도, 출처와 MIT 제외 범위를 고지한다.
- 긴 sticky·빈 스크롤 공간·스크롤 장면 전환 없음. 자연스럽게 스크롤하며 노치/목록/달력/편집기 버튼·체크·알림·이전/다음·초기화로 체험한다. 기능별 한 줄 설명은 실제 표시 상태와 연결한다.
- 앱 UI의 녹색 내 할 일·파란 LMS·빨간 지난 마감, 다크 편집기의 검정 바탕을 유지. 알림 배경은 목록/달력 패널과 같은 역할 색. 앱보다 확대된 허구 예시이며 실제 LMS 데이터는 사용하지 않는다.
- hover 가능한 마우스는 노치 진입 시 펼침·노치/패널 밖 이탈 시 접힘. 터치/키보드 조작은 별도 유지, 숨긴 영역의 초점을 적절히 이동한다. 모바일은 화면 확대/전체 보기 제공.
- 움직임 감소에서는 설명 등장/이동 효과를 끈다. 무한 rAF·배경 무한 애니메이션 없음. 5초 알림은 유한 timeout, **사용자 실시간 시계 요청에 한해** 보이는 무대에서 다음 분 경계 timeout 하나를 재예약한다. 무대/탭 숨김 시 취소. 이 웹 예외를 앱 타이머 허용으로 확대하지 않는다.
- 공개 전 주 행동은 ‘공개 준비 중’과 체험/설치 안내, 실제 다운로드/Issues 활성화는 별도. 사용자 최종 시각 승인은 완료, 최종본 환경별 독립 QA·공개 자산 권리 확인은 게시 전 과제로 유지한다.
