# DoIt PRD v0.14

> 최종 수정: 2026-11-11 (공개 1.0.2와 실제 확인 범위 반영)
> 이 문서가 "무엇을 만드는가"의 기준이다. 변경은 문서 관리 담당자를 통해서만 한다.

## 1. 한 줄 정의
어느 화면에서 작업 중이든 **메인 디스플레이 노치에 마우스를 대면** 할 일 목록이 부드럽게 펼쳐지고, 그 자리에서 바로 추가·체크까지 할 수 있는 macOS 메뉴바 앱.

## 2. 배경과 목표
- 문제: 할 일을 메모장에 적어두면, 확인하거나 추가하려고 다른 화면으로 넘어가야 한다.
- 목표: **화면 전환 0회**로 할 일 확인·추가·완료 처리.

## 3. 사용 환경
- MacBook Air M4 13", macOS 26.6.2, Xcode 26.6, XcodeGen 2.46.0 (T-001에서 확인)
- 프로젝트는 iCloud 동기화 폴더 밖에서 빌드한다(동기화로 코드 서명 실패·충돌 사본 발생 가능).
- 현재 개인 사용 중이며, 한동대 LMS 사용 학생을 위한 무료 MIT 앱으로 공개됐다. Apple 개발자 등록·공증·앱스토어 배포는 하지 않는다.
- 사용자는 전체화면에서도 메뉴바가 보이도록 설정해 둠
- 외부 모니터를 연결해 **주 디스플레이로** 쓰는 경우가 있음

## 4. 용어
| 용어 | 정의 |
|---|---|
| 메인 디스플레이 | 메뉴바가 있는 주 디스플레이 (시스템 설정 > 디스플레이의 "주 디스플레이"). 코드상 `NSScreen.screens.first` |
| 실제 노치 | 메인 디스플레이에 물리 노치가 있는 경우 그 영역 |
| 가상 노치 | 메인 디스플레이에 노치가 없을 때(외부 모니터) 상단 중앙에 DoIt이 직접 그리는 검은 노치 모양. 빈 공간을 채우고 hover 영역 역할을 한다 |
| 패널 | 노치에서 펼쳐지는 할 일 목록 UI |

## 5. 기능 요구사항

### F1. 메뉴바 아이콘
- 메뉴바에 DoIt 아이콘(SF Symbol, 예: `checklist`) 표시
- 메뉴: **DoIt 켜기/끄기**, (T-006) **전체 편집기…**, (T-007) **설정…**, (T-007) **LMS 지금 새로고침**, 종료

### F2. 표시 위치
- **메인 디스플레이에만** 표시한다.
- 실제 노치가 있으면 그 위치/크기에 맞춘다.
- 노치가 없으면 상단 중앙에 **가상 노치**를 그려 같은 방식으로 동작한다.
- 모니터 연결/해제, 주 디스플레이 변경 시 자동 재배치.

### F3. 상태와 동작
| 상태 | 설명 |
|---|---|
| OFF | 꺼짐. hover 감지 안 함, 아무것도 그리지 않음(가상 노치도 숨김) |
| IDLE | 켜짐·접힘. 노치 영역 hover 감지 중 |
| EXPANDED | 펼쳐져 목록 표시 |
| EDITING | 패널 안 입력창/날짜 선택 사용 중 |

- OFF → 켜기: **한 번 펼쳐서 보여줌**. 3초 안에 마우스가 들어오지 않으면 접힘.
- **앱을 실행하면(로그인 시 자동 실행 포함) 켜진 상태로 시작**하고 같은 3초 미리보기를 보여준다 (2026-11-08 사용자 결정, T-010)
- 이미 실행 중일 때 앱을 다시 열면 새로 띄우지 않고 같은 미리보기만 보여준다 (OFF면 켜지 않음, T-010)
- IDLE → 노치에 마우스 진입: **즉시** 펼침 (지연 없음).
- EXPANDED → 패널 밖으로 마우스 이탈: 내용이 먼저 흐려지고 패널이 **서서히 노치 쪽으로 올라가며** 사라짐 (~0.4초).
- 접히는 도중 마우스가 다시 들어오면 즉시 다시 펼침.
- EDITING 중에는 마우스가 나가도 **접히지 않음**.
- **Enter로 추가하면 입력이 끝나고 EXPANDED로 돌아간다** (입력창 커서 해제). 이때 마우스가 밖이면 바로 접히고, 안이면 마우스가 나갈 때 접힌다. 연달아 추가하려면 입력창을 다시 클릭한다. (T-001c 사용자 결정)
- Esc: 입력을 끝내고 접는다. 마우스가 노치 위에 있어도 바로 다시 펼치지 않고, 한 번 나갔다 들어오면 펼친다. (T-002에서 적용)
- 패널 바깥 클릭: 입력을 끝내고, 마우스가 밖이면 접는다.
- 끄기: 즉시 접고 hover 감지 중단.

### F4. 목록 표시
- 정렬: **마감일 오름차순**, 같은 날짜는 생성순
- D-day 표시: `D-3`, `D-Day`, `D+2`
- 마감 지난 미완료 항목은 빨간색 강조
- 완료 항목은 목록 아래로 내리고 흐리게 + 취소선
- **완료 항목은 체크한 다음 날부터 패널에서 숨긴다** (`doneAt`이 오늘 0시 이전이면 숨김). 파일에서는 지우지 않는다. 체크한 당일에는 다시 체크 해제할 수 있다
- 패널 높이는 **내용에 맞춰 자동 조절**하고, 최대 높이를 넘으면 스크롤

### F5. 빠른 추가 (패널 안)
- 입력창 + 날짜 선택. 날짜 기본값 = 오늘
  - 입력창 옆 날짜 버튼(기본 표시 "오늘")을 누르면 **패널 안에서** 날짜 선택 영역이 펼쳐진다 (별도 팝업 창 없음)
  - 빠른 선택: `오늘`, `내일`, `+1주` + 달력
  - 날짜 선택 중에는 EDITING과 같이 취급해 마우스가 나가도 접히지 않는다
- Enter로 추가. 추가 후 날짜는 다시 "오늘"로 돌아간다
- **한글 입력(IME 조합)이 정상 동작해야 한다** (필수)

### F6. 완료 체크
- 항목 체크박스 클릭으로 완료/미완료 토글

### F7. 수정·삭제
- **삭제는 패널에서**: 항목에 마우스를 올리면 오른쪽에 `×` 버튼이 보인다. 한 번 누르면 `삭제?`(빨간색)로 바뀌고, 한 번 더 누르면 삭제. 그 사이 마우스가 항목을 벗어나면 취소된다
- **제목·마감일 수정은 전체 편집기(T-006)에서만** 한다

### F8. 알림 (T-005) — 노치 알림
- **하루 한 번, 마감 당일 오전 9:00**에 그날 마감인 항목을 모아 **요약 알림 1개** (`오늘 마감 n개`, 앞의 최대 3개 제목, LMS는 `[짧은 과목명]`, 넘치면 `외 n개`)
- **노치 알림 (2026-11-08 사용자 결정)**: macOS 오른쪽 배너 대신, 아이폰 다이나믹 아일랜드처럼 **노치가 옆으로 넓어지며** 알림을 보여준다 (바탕: 밝은 모드 흰색, 어두운 모드 검정)
  - 약 **5초** 표시 후 노치로 줄어든다
  - 오른쪽에 작은 **`×` 닫기 버튼** — 누르면 즉시 닫힘 (긴박한 상황 대비)
  - 떠 있는 동안 **마우스를 올리면 펼치지 않고 5초 자동 닫힘만 미룬다**(×를 누를 수 있게). **클릭하면** 평소 패널로 펼쳐진다(목록 화면·오늘) — 2026-11-08 사용자 결정
  - DoIt을 메뉴로 **끈(OFF) 상태에서도** 앱이 실행 중이면 노치 알림을 띄운다 (hover 기능과 별개)
- **DoIt이 종료돼 있을 때 대비**: 앱 종료 직전에 macOS 기본 알림을 대신 예약해 두고, 다음 실행 때 지운다 → 앱을 꺼둔 날도 알림을 놓치지 않음
- 맥이 잠자기 중이라 9:00을 지나쳤으면 **깨어날 때** 그날 노치 알림을 띄운다(그날 한 번만)
- **실사용 확인 (2026-11-09, T-005 J)**: 9:00 알림이 표시됨(`notchAlertLastShownDay = 2026-11-09`). 사용자는 화면에서 놓쳤으나 **표시 시간 5초는 유지**(사용자 결정). info 등급 로그는 디스크에 남지 않아 확인에 쓸 수 없었음 → 알림 로그를 notice 등급으로(T-013). '덮어뒀다 9시 이후 열기'는 다음 기회에 확인
- 대상: **미완료 내 할 일**(달력에서 추가한 것 포함) + **체크 안 한 LMS 과제**(`lms.json` 기준, history 제외)
- 오늘 9:00이 지난 뒤 오늘 마감으로 추가한 할 일은 알리지 않는다
- 설정 '알림': `내 할 일 마감 알림`, `LMS 과제 알림` 스위치(기본 켬), **`노치 알림 일시 중지`** 스위치(수업·발표 중 등, 켜두면 노치 알림을 띄우지 않음, 기본 끔), 다음 알림 미리보기, `테스트 알림 보내기`
- 집중 모드(방해 금지)는 노치 알림이 따르지 않는다 → 위 '일시 중지'로 대신한다
- 권한: macOS 알림 권한은 종료 시 대신 예약하는 기본 알림에만 필요. 거부돼 있어도 노치 알림은 동작하며, 설정에 안내 표시

### F9. 전체 편집기 (T-006) — 범위 확정 2026-11-08
- 앱 안의 창(WKWebView)에 웹 UI를 띄운다. **로컬 서버 없음**, 앱 ↔ 웹은 JS 브리지로 통신
- **여는 곳**: 메뉴바 메뉴 `전체 편집기…` + 패널 머리줄 아이콘(📆 · **편집기** · ⚙). 이미 열려 있으면 그 창을 앞으로
- **내 할 일**
  - **제목·마감일 수정** (제목 빈칸 불가, 한글 입력 조합 중 Enter는 저장하지 않음)
  - **여러 개 골라 한 번에** 완료 / 미완료 / 삭제 (삭제는 확인 한 번 더)
  - **검색**(제목) · **정렬**(마감일순 기본 / 추가순)
  - 보이는 항목은 패널과 같은 규칙(미완료 전부 + 오늘 체크한 완료). 새 할 일 추가는 패널에서
- **LMS 과제**: **보기 + 체크만** (과제명·과목명·마감일 수정 불가, LMS 읽기 전용 원칙 D-011). 패널 LMS 칸과 같은 항목(`lms.json`, 설정한 N주)
- 편집기에서 바꾼 내용은 바로 저장되고 패널·달력·알림에 반영. 패널에서 바꾼 내용도 열린 편집기에 바로 반영
- 편집기는 네트워크에 접속하지 않는다 (앱에 들어 있는 파일만 표시)
- 외부 브라우저가 꼭 필요해지면: 편집기 열 때만 서버 시작, 적용/일정 시간 미사용 시 종료, `127.0.0.1` 전용, 실행마다 임의 포트 + 토큰

### F10. 로그인 시 자동 실행 (T-010 ✅)
- 설정 창 '일반'의 `로그인 시 자동 실행` 스위치(기본 끔), `SMAppService.mainApp`. 자체 서명 앱에서도 별도 승인 없이 동작 (T-010 확인)

### F11. LMS 과제 연동 (T-007)
학교 LMS(LearningX, Canvas 계열) 캘린더의 과제·마감일을 패널에 함께 보여준다. 보안·동기화 구조는 `ARCHITECTURE.md` §3.8을 따른다.
- **연결 방식**: 사용자가 LMS 캘린더의 '캘린더 피드'에서 발급받은 개인 `.ics` 주소를 설정 창에 붙여넣는다. 화면 크롤링·아이디/비밀번호 사용은 하지 않는다.
- **설정 창**
  - LMS 연동 켜기/끄기 (기본: 끔)
  - 피드 주소 입력 (입력 후에는 가려서 표시, "주소 바꾸기"만 가능)
  - 가져올 기간: 오늘부터 **N주** (기본 2주, 1~8주)
  - 마지막 동기화 시각과 상태 표시
- **패널 표시**
  - 내 할 일 목록과 분리된 **"LMS" 칸**을 **내 할 일 위**에 표시. 칸 제목을 눌러 접기/펼치기 가능(상태 기억). 연동이 켜져 있고 항목이 있을 때만 보인다
  - 마감이 지난 미완료 LMS 과제는 **마감 다음 날까지 빨간색**으로 보이고 그 뒤 숨긴다. 체크한 LMS 과제는 내 할 일과 같이 다음 날 숨긴다
  - 알림: 체크하지 않은 LMS 과제도 **마감 당일 오전 9시 알림** 대상 (F8, T-005에서 구현). 설정 창에서 LMS 알림만 따로 끌 수 있다
  - 항목: 과제 이름, 과목명, 마감일(D-day). 마감 시각이 있으면 함께 표시(예: `D-Day 23:59`). 정렬은 마감순
  - 과목명은 화면에서 괄호 속 영문명을 뺀 짧은 형태로 보여준다 (예: `컴퓨터구조(Computer Architecture) 02분반` → `컴퓨터구조 02분반`). 저장은 원문 그대로
- **피드 형식 (2026-11-07 사용자 확인)**: 피드에는 교수자가 기한을 건 **과제만** 들어 있다. 과제는 `UID:event-assignment-<번호>`, 제목은 `SUMMARY:<과제명> [<과목명>]` 형태. `DESCRIPTION`·`X-ALT-DESC`·`URL`에는 강의자료 파일 링크가 들어 있으므로 **읽지도 저장하지도 않는다**
  - 체크 가능 (완료 표시는 DoIt 안에서만 저장, LMS에는 보내지 않음). 제목·마감일은 수정 불가(읽기 전용)
- **동기화 시점** (주기적 타이머 없음). 아래 시점에 오더라도 **마지막 동기화 후 6시간이 안 지났으면 건너뛴다.**
  - 앱 실행 시 / 잠자기에서 깨어날 때 / 패널을 펼쳤을 때
  - 메뉴의 "지금 새로고침": 6시간 제한은 무시하지만 **최소 5분 간격**
  - 하루 최대 접속은 대략 4~10회 수준. 일반 캘린더 앱이 구독 캘린더를 새로 고치는 것과 같은 수준으로 유지한다
- **"N주"와 동기화 간격은 다른 개념이다.** N주는 *어느 기간의 마감까지 보여줄지*(표시 범위), 6시간은 *얼마나 자주 새 과제를 확인할지*(새로 고침 간격)다.
- **오류 상태**
  - 주소가 무효(401·404 등): 기존 목록은 유지하고 LMS 칸에 "연결이 끊겼어요 · 피드 주소 다시 넣기" 표시
  - 오프라인·서버 오류: 마지막으로 받은 목록을 보여주고 "마지막 동기화: n시간 전" 표시
  - 피드 형식 오류: 기존 목록 유지, 설정 창에 오류 표시
- **규정·보안 원칙**
  - 가져오는 정보는 과제 이름·마감일·과목명뿐. 강의자료·설명 본문은 저장하지 않는다
  - 데이터는 맥 안에만 둔다. 외부 서버나 AI 서비스로 보내지 않는다
  - 피드 주소는 비밀번호처럼 취급한다: **이 맥의 본인만 읽을 수 있는 파일 1개**(`~/Library/Application Support/DoIt/lms-feed-url`, 파일 권한 600·폴더 700, Time Machine 백업 제외)에만 저장하고, 로그·저장 공간 화면·기록 백업·git·문서·프롬프트·대화에 남기지 않는다. 설정 창 표시는 "🔒 이 맥에만 저장됨" (T-013, D-009 개정. T-010까지는 키체인)
  - LMS가 공식으로 제공하는 **캘린더 구독 기능만** 쓴다. 로그인 화면·API·다른 페이지에는 접속하지 않는다
  - 접속 시 쿠키·로그인 정보를 보내지 않고, 응답을 디스크 캐시에 남기지 않는다
  - 피드의 일정 중 **과제(마감) 항목만** 남기고 나머지 일정·설명 본문은 버린다
  - 학교 공지(GPAI 등)와 충돌하면 기능을 끈다. 공지 확인 전에는 기본값 "끔" 유지
- **학교 공지 검토 (2026-11-07)**: AI혁신센터의 GPAI 공지는 *외부 서비스가 강의자료 등 저작물을 무단 수집(크롤링)하는 것*을 금지 대상으로 삼는다. DoIt은 (1) 강의자료를 가져오지 않고 과제명·마감일·과목명만, (2) LMS가 공식 제공하는 개인 캘린더 피드만, (3) 내 맥 안에서만 쓰고 외부 서버·AI로 보내지 않으므로 공지의 우려와 겹치지 않는다고 판단. 다만 공지가 캘린더 피드 사용을 명시적으로 허용한 것은 아니므로, 학교의 다른 안내가 나오면 다시 검토한다
- **영구 금지**: 강의자료·게시글·첨부파일 접근, LMS 화면 크롤링, LMS 데이터를 AI 서비스에 보내는 기능
- ★ **영구 규칙 — LMS 읽기 전용**: DoIt은 LMS에 **피드 읽기 요청(GET)만** 보낸다. 체크 상태·할 일·기록 등 사용자 데이터를 LMS나 그 밖의 외부로 **절대 보내지 않는다**. (T-007에서 테스트로 고정)
- 저장 범위: 피드의 과제 중 **오늘 ~ 8주(최대값)** 를 `lms.json`에 두고 화면에서 설정한 N주로 거른다(기간을 바꿔도 재접속 없음). **마감이 지난 과제는 `lms-history.json`으로 옮겨 보관**한다(F13)

### F12. 달력 보기 (T-009)
- 패널 위쪽 📆 버튼 → 목록 대신 **월 단위 달력**이 패널 안에서 열린다. `◀` `▶`로 달 이동, `오늘` 버튼으로 이번 달 복귀
- 날짜 칸: 내 할 일·LMS 과제를 **다른 색 점**으로 표시(완료는 흐리게), 오늘 날짜 강조
- 날짜를 누르면 달력 아래에 **그날 마감인 내 할 일 + LMS 과제** 목록
  - **지난 날짜: 보기 전용** (체크·추가 불가)
  - **오늘·미래 날짜: 체크 가능 + 그 날짜로 할 일 추가 가능** (입력창 날짜가 그 날짜로 미리 설정)
  - 삭제는 기존 목록 화면에서만
- 달력 화면 동안 패널이 커질 수 있다(최대 높이 규칙은 F4와 같음). 달력 화면은 칸 크기(54)를 지키려고 최대 높이를 **화면의 70%, 상한 640pt**까지 허용한다(2026-11-08 사용자 결정). **직전 화면 유지 (2026-11-08 사용자 요청)**: 패널이 접혔다 다시 펼쳐져도 보던 화면(목록/달력)·보던 달·선택한 날짜를 그대로 보여준다
  - 날짜가 바뀌면(자정) 화면 종류는 유지하고, 선택한 날짜가 '어제의 오늘'이었다면 새 오늘로 옮긴다
  - 메뉴로 DoIt을 끄고 다시 켜거나 앱을 다시 실행하면 목록 화면·오늘로 시작한다
- 내 할 일 행에도 잘린 제목을 마우스를 올려 전체로 보는 상자를 넣는다 (LMS 행과 같게)

### F13. 기록 보관과 정리 (T-009)
- **내 할 일**: 완료 항목은 화면에서만 숨기고 `todos.json`에 남는다(F4). `×` 삭제는 진짜 삭제라 달력에도 안 보인다
- **LMS 과제 기록**: 마감이 지난 과제는 피드에서 사라져도 `lms-history.json`에 UID 기준으로 보관(과제명·과목명·마감일·체크 여부만). 마감 전 과제가 피드에서 사라지면(교수자 삭제) 보관하지 않는다
- **기록 보관 기간**(설정): 6개월 / **1년(기본)** / 2년 / 정리 안 함
- 정리 대상: 보관 기간보다 오래된 **완료한 내 할 일**과 **LMS 기록**(+그 체크 상태). **완료 안 한 내 할 일은 대상 아님**
- **자동으로 지우지 않는다.** 대상이 생기면 메뉴에 `기록 정리 필요 (n개)`, 설정 창에 안내 → 사용자가 확인 창에서 `백업 후 정리` / `그냥 정리` / `나중에` 선택
  - 백업: `~/Library/Application Support/DoIt/archive/기록-YYYYMMDD.json`
- 설정 창에 `지금 정리…`, `모든 기록 초기화…`(두 번 확인) 버튼

### F14. 저장 공간 표시 (T-009)
- 설정 창 "저장 공간": 파일별 크기·항목 수(`todos.json`, `lms.json`, `lms-history.json`, `lms-state.json`, `archive/`), 합계, 정리 대상 수, DoIt 현재 메모리 사용량

### F15. 디자인 (2026-11-07 확정, T-011에서 적용)
- 모든 화면은 **`docs/DESIGN.md`(디자인 확정안)** 를 따른다: macOS 기본 스타일, 밝은·어두운 화면 자동 전환, 내 할 일 = 이화 그린, LMS = 남색·파랑, 지난 마감 = 빨강
- 노치 패널 배치(위→아래): 머리줄(DoIt · 오늘 날짜 · 📆 · ⚙) → 입력창 → LMS 칸 → 구분선 → 내 할 일
- 설정 창: 사이드바 구조 (일반 / LMS 연동 / 알림 / 기록 보관 / 저장 공간). 아직 기능이 없는 항목(알림 = T-005, 로그인 시 자동 실행 = T-010)은 해당 작업에서 추가
- 앱 아이콘·메뉴바 템플릿 아이콘(D안 "검은 목록")은 T-010

### F16. 업데이트 (T-012b ✅ — 이 Mac에서 1.0.0→1.0.1 원격 실측)
- 메뉴바 메뉴·설정 ‘일반’에 `업데이트 확인…`, 설정에 `자동으로 업데이트 확인` 스위치(기본 켬).
- Sparkle 2로 약 하루 간격(86400초)에 자동 확인한다. 앱 종료·잠자기·오프라인으로 정확한 시각의 하루 1회는 보장하지 않는다. 끄면 예약 확인을 중단하고 수동 버튼은 유지한다.
- 새 버전 안내 후 다운로드·설치는 사용자가 선택한다. 자동 다운로드·자동 설치 선택지도 제공하지 않는다. 확인 허용을 묻는 별도 첫 실행 창은 띄우지 않는다.
- 할 일·LMS 데이터·피드 주소를 업데이트 경로에 보내지 않으며 시스템 프로파일 전송도 끈다. 업데이트 서버는 통신에 필요한 IP·일반 HTTP 요청 정보를 받을 수 있다.
- 배포 시 appcast는 정해진 HTTPS 주소 1곳, 다운로드는 해당 프로젝트 GitHub Releases와 자산 제공 경로만 사용한다. 설치 후 기존 데이터·권한 유지, 앱이 켜진 상태로 다시 실행되어야 한다.
- 로컬 0.9.2(8)→(9)와 이 Mac의 원격 1.0.0→1.0.1 업데이트에서 사용자 보고 추가 암호·허용 창은 0번이었다. 1.0.2로의 실제 업데이트, 다른 맥·새 계정·Intel은 미실측이다.
- 정식 feed 주소는 https://prestige-kim.github.io/DoIt/appcast.xml이며 공개됐다. 번들 `DoItDistributionEnabled=true`이고 내부 검증 구성의 loopback은 별도 유지한다.

## 6. 데이터 모델
```
Todo {
  id: UUID
  title: String
  dueDate: 날짜(시간 없음, 로컬 기준 yyyy-MM-dd)
  isDone: Bool
  createdAt: Date
  updatedAt: Date
  doneAt: Date?
}
```
- 마감일을 지정하지 않으면 **생성한 날짜로 고정**한다 (다음 날이 되어도 바뀌지 않고 `D+1`로 표시).
- 저장 위치: `~/Library/Application Support/DoIt/todos.json` (`schemaVersion` 포함, 원자적 쓰기)
- 형식을 바꿀 때(`schemaVersion` 2 이상)는 기존 파일을 백업한 뒤 변환한다. 구체 방식은 해당 지시서에서 정한다.

```
LmsItem {            // lms.json (읽기 전용 캐시, 동기화할 때마다 통째로 교체)
  uid: String        // .ics의 UID (항목 식별자)
  title: String
  courseName: String?
  dueDate: 날짜(로컬 기준)
  dueTime: 시각?     // 피드에 시각이 있으면 보관
}
LmsCheckState {      // lms-state.json (사용자 체크 상태만, UID 기준)
  doneUids: [String: Date]
}
```
- LMS 데이터는 `todos.json`과 **섞지 않는다.**
- `lms-history.json`: 마감 지난 LMS 과제 기록 (`LmsItem`과 같은 4개 항목 + 보관 시작 시각). 체크 상태는 그 과제가 history에 있는 동안 `lms-state.json`에 유지한다 (T-007의 "사라진 체크 30일 뒤 정리"를 대체)
- 기록 보관 기간 설정과 정리 알림 상태는 UserDefaults
- 피드 주소는 `lms-feed-url`(권한 600, 백업 제외)에 저장한다. 저장 공간 화면·기록 정리 백업·'모든 기록 초기화'의 대상이 아니며, **LMS 연결 해제 때만** 지운다 (T-013)

## 7. 비기능 요구사항
- 대기(IDLE) 시 CPU 평균 **0.5% 이하**, 메모리 **100MB 이하** (활동 모니터 기준)
- 펼침/접힘 애니메이션 끊김 없음
- 네트워크는 LMS 연동 시 개인 피드 GET과 F16의 업데이트 확인·다운로드만 허용한다. 두 경로는 분리하며 사용자 데이터 외부 전송은 계속 금지한다. 로컬 업데이트 검증 예외는 ARCHITECTURE D-020을 따른다.
- 성능 금지 규칙은 `ARCHITECTURE.md` §5

### 배포 기준
- 최우선 목표: 학생의 **암호 입력은 첫 설치 때 관리자 암호 1번뿐**, 업데이트 후 차단·암호 창은 0번. 이 Mac의 1.0.0→1.0.1 원격 업데이트에서 사용자 보고 0번, 다른 Mac에서는 미확인.
- 첫 공개 버전은 1.0.0(11), 이후 1.0.1(12), 1.0.2(13) 순서다. 기존 ZIP·태그는 교체하지 않는다.
- 공개 대상: 앱·테스트·스크립트·프로젝트 설정·이 세 기준 문서·README·MIT LICENSE·외부 코드 고지·랜딩 소스. 내부 작업 지시서·보고서·인수인계·에이전트 규칙은 제외.
- MIT 저작권자: **2026 prestige-kim**. 공개 기준 문서의 내부 문서 링크·개인 경로는 정리한다(2026-11-09 사용자 결정).
- README·랜딩·커밋에 AI 작성 표기를 넣지 않는다. LMS 데이터의 AI 서비스 전송 금지 설명은 보안 정책으로 유지한다.
- 설치본은 자체 서명 인증서와 번들 ID를 유지한다(D-017). Intel은 universal 빌드만 확인했고 실제 동작은 미검증이다.

## 11. 결정 기록
- LMS 연동: **개인 캘린더 피드(.ics) 방식.** 크롤링·계정 정보 사용 없음, 웹 로그인 세션과 무관. 피드에 문제가 생기면 Canvas 개인 액세스 토큰 방식을 검토한다. (ARCHITECTURE D-008~D-010)
- 피드 주소 저장: **키체인 → 본인만 읽는 파일 (2026-11-08 사용자 결정, T-013)**. 자체 서명 앱은 업데이트마다 키체인 암호 창이 떠서(T-010 실측) 배포 사용자의 인증 횟수를 최소로 한다는 목표에 어긋난다. 대가(같은 사용자 계정의 다른 프로그램이 읽을 수 있음)는 주소로 가능한 일이 과제 목록 읽기뿐이고 노출 시 LMS에서 재발급할 수 있어 허용 (ARCHITECTURE D-009·D-018)
- 저장소: **자체 JSON 사용, Apple 미리알림 연동 안 함.** 편집을 패널 안 네이티브 UI로 하고 편집기는 서버 없는 앱 내 WebView라, 직접 만드는 비용과 자원 소모가 작다. 미리알림 연동은 "그냥 미리알림 쓰면 된다"는 문제도 있다.

### 릴리스 준비 원칙 (T-012c 구현·로컬 검증 완료)
- 깨끗한 main에서 버전·설정 확인 → Release 빌드·포장 → EdDSA 서명 검증 → zip/manifest/appcast 후보를 로컬 dist에 준비한다. 자동 커밋·업로드·게시 없음.
